Stage 7.1.1 build fix

Root cause of previous GitHub Actions failure:
- cargo build was run at the idevice workspace root without -p.
- That selected workspace members including idevice-tools.
- idevice-tools depends on nusb 0.2.4.
- nusb has no iOS backend, so it cannot compile for aarch64-apple-ios.

Fix:
- Build ONLY package idevice-ffi (-p idevice-ffi).
- Disable its default/full feature set.
- Enable only Stage 7.1 features: obfuscate, core_device, tunnel_tcp_stack.
- tunnel_tcp_stack in idevice-ffi pulls core_device_proxy + rsd + remote_pairing.
- Use --locked so the pinned idevice commit's Cargo.lock is honored.

Do NOT update nusb and do NOT clear cargo cache as a primary fix.
